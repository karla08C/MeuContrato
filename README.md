# Meu Contrato

Sistema desenvolvido em Python para automatizar a geração de contratos de trabalho.

## Funcionalidades (em desenvolvimento)

- Leitura de planilhas Excel
- Geração automática de contratos
- Exportação para PDF
- Organização dos arquivos

## Tecnologias

- Python
- Pandas
- OpenPyXL
- Python-Docx
